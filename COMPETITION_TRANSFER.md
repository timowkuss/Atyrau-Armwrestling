# Перенос соревнования между компьютерами (.armwrestling)

## Зачем это нужно

Соревнование проводится офлайн на ноутбуке организатора. Если соревнование
нужно продолжить на другом компьютере (запасной ноутбук, сбой устройства,
переезд на второй стол), все данные переносятся в одном файле
`.armwrestling` — архив соревнования целиком: состав участников, сетки,
результаты, клубный рейтинг, очередь синхронизации и привязки id.

## Файл .armwrestling

Обычный ZIP-архив с JSON-разделами:

| Раздел | Содержимое |
|---|---|
| `metadata.json` | версия формата, id соревнования, счётчики, SHA-256 checksum |
| `competition.json` | запись турнира + `competition_source` + `session_id` |
| `categories.json` | категории |
| `participants.json` | участники |
| `matches.json` | все матчи (завершённые и нет) |
| `athletes.json` | спортсмены, привязанные к соревнованию |
| `coaches.json` | тренеры привязанных спортсменов |
| `clubs.json` | клубы привязанных спортсменов/тренеров |
| `results.json` | снапшот завершённых матчей |
| `rating_events.json` | начисленные события клубного рейтинга |
| `overrides.json` | обходные оценки двоеборья |
| `bracket_generations.json` | счётчики генераций сеток |
| `sync_operations.json` | неотправленные операции очереди синхронизации |
| `id_map.json` | привязки локальный id → серверный id |
| `photos/*` | фотографии (опционально) |

**Целостность:** SHA-256 checksum по всем обязательным разделам. Любое
изменение файла при переносе (битый флеш-накопитель, случайная правка,
файловый менеджер) будет обнаружено при импорте — приложение откажет в
импорте с понятным сообщением.

**Пароль (опционально):** файл можно защитить паролем. Это защита от
случайного доступа, а не криптозащита — не используйте его для передачи
секретных данных.

## Экспорт

1. Откройте соревнование.
2. Нажмите **«📦 Экспорт»** в нижней панели рабочей области.
3. Перед экспортом приложение проверяет целостность соревнования
   (категории, участники, матчи, победители, рейтинг). При наличии проблем
   экспорт заблокирован с перечнем проблем — файл с повреждёнными данными
   не создаётся.
4. Выберите место и имя файла. Экспорт полностью офлайн — интернет не нужен.

**Аварийный экспорт (🚨)** — создаёт копию «как есть», без проверки
целостности. Используйте, когда нужно максимально быстро сохранить данные
(например, ноутбук отключается). Файл всё равно валиден и перечитывается
приложением после записи.

## Автоматические резервные копии

Приложение автоматически создаёт резервную копию соревнования:

- после каждого завершённого матча;
- после создания сетки;
- после завершения турнира;
- периодически, пока идут изменения.

Файлы кладутся в папку `backups/` рядом с базой данных:
`<Название>_auto_ГГГГ_ММ_ДД_ЧЧ-ММ-СС.armwrestling`. Хранятся последние
**10** файлов, старые удаляются. Аварийные экспорты — с меткой
`_emergency_`.

Индикатор в шапке соревнования показывает актуальность последней копии и
число несинхронизированных операций:

- 🟢 — все данные сохранены, синхронизация в порядке;
- 🟡 — есть несинхронизированные операции или свежая копия давно не делалась;
- 🔴 — ошибка синхронизации (интернет/токен): записи не потеряны, отправка
  повторится автоматически.

## Импорт

1. На экране списка соревнований нажмите **«📥 Импорт»** (или «Импорт
   соревнования» в шапке списка).
2. Выберите файл `.armwrestling`.
3. Приложение открывает окно **предпросмотра**: название, дата, число
   участников/матчей, завершённость, число операций синхронизации.
4. После подтверждения данные записываются в **одной транзакции**: если
   что-то пойдёт не так, изменения откатываются целиком.

### Если соревнование с таким id уже существует

Приложение предложит три варианта:

- **Заменить (восстановить из файла)** — данные существующего соревнования
  заменяются данными из файла. Нужно, когда вы вернули ноутбук в работу
  после сбоя («режим восстановления»). Рейтинг не начисляется повторно:
  переносятся уже применённые события.
- **Открыть существующее** — просто открыть локальную версию.
- **Отмена** — не импортировать.

Если файл создан **в другой сессии** (на другом компьютере или после
восстановления), приложение явно предупреждает об этом — защита от
неосознанного перезаписывания данных одной и той же копии соревнования
с двух компьютеров.

## Что переносится, а что нет

Переносится:

- все данные соревнования (расписание, сетки, результаты, двоеборье);
- спортсмены, тренеры и клубы, привязанные к соревнованию;
- начисленный клубный рейтинг (история событий этого турнира);
- очередь неотправленных операций синхронизации и привязки id — после
  импорта на новом компьютере они доставятся на сервер как обычно, без
  дублей (id операций сохраняются);
- фотографии участников, если включено.

Не переносится и не затрагивается:

- соревнования и данные других турниров;
- начисления рейтинга «повторно» — начисление невозможно по конструкции
  (события идемпотентны, уникальный индекс
  `(club_id, athlete_id, tournament_id, reason, description)`).

## Безопасность

- Файл проверяется **полностью до любых изменений** базы: формат, checksum,
  версии (формат экспорта и схема данных), структура, внутренние ссылки,
  дубликаты.
- Все изменения — в одной транзакции (`BEGIN IMMEDIATE ... COMMIT /
  ROLLBACK`), поэтому обрыв питания/процесса в середине импорта не оставит
  частично импортированные данные.
- Служебная БД синхронизации записывается только после успешной записи
  основных данных.
- Файл более новой версии приложения отклоняется с подсказкой обновить
  приложение.
- «Чужие» операции других соревнований и их привязки id в очередь не
  копируются.

## Восстановление после сбоя

1. Папка `backups/` в каталоге приложения содержит копии соревнования.
2. При запуске приложение проверяет целостность локальной БД (PRAGMA
   quick_check) и сообщает о проблемах. При повреждении — предложит
   восстановить из последнего файла.
3. Также можно вручную: **«📥 Импорт» → файл из `backups/`** → выбрать
   «Заменить».

## Версии

- Формат `.armwrestling`: v1.
- Совместимость в одну сторону: файлы текущей версии читаются более новыми
  приложениями; файлы более новых версий — отклоняются с понятным
  сообщением.

## Тесты

Пакет `desktop-app/tests/export_import/`:

- 71 тест: экспорт/импорт, кругосветная проверка данных, дубликаты,
  замена, битые файлы, checksum, версии, пароль, целостность
  (спортсмены/тренеры/клубы/матчи), рейтинг не начисляется повторно,
  очередь синхронизации и id переезжают, откаты, фотографии, менеджер
  бэкапов (ротация 10, интервал, аварийный экспорт, проверка БД).
- Chaos-тест: случайные повреждения архива — импорт либо успешен и
  корректен, либо падает, не оставляя частичных данных.

Запуск:

```
cd desktop-app
python -m unittest discover -s tests/export_import -p "test_*.py" -t .
```

## Ограничения

- Перенос подразумевает «чистую» целевую установку или восстановление
  своего же соревнования. Для слияния с чужими спортсменами (совпадающие
  локальные id) импорт откажет — переносите соревнование на компьютер без
  конфликтующих записей.
