# Установка «Atyrau Armwrestling» на другой Windows-компьютер

Полное пошаговое руководство: как взять готовый установщик, установить
приложение на новый ПК и сразу начать работать. Никакого Python, pip или
настройки — всё уже внутри одного файла.

---

## Что нужно для установки

- **Один файл:** `build\AtyrauArmwrestlingSetup.exe` (~30 МБ)
- **Компьютер:** Windows 8/10/11 64-bit
- **Интернет:** нужен для синхронизации с сайтом; без него приложение
  продолжает работать локально (офлайн-очередь), а данные улетают на
  сервер после появления сети.

Не нужно: Python, pip, VS Code, PostgreSQL, установка библиотек, права
администратора, запуск из командной строки.

---

## Шаг 1. Перенесите установщик на новый компьютер

Скопируйте файл `AtyrauArmwrestlingSetup.exe` на новый ПК любым способом:

- флешка / внешний диск;
- облако (Google Drive, Dropbox, Яндекс.Диск);
- по сети/мессенджеру.

Альтернатива: вместо установщика можно взять `AtyrauArmwrestling_Portable.zip`,
распаковать и запустить `AtyrauArmwrestling.exe` — работает без установки
(см. Приложение Б).

---

## Шаг 2. Установите приложение

1. Дважды кликните по `AtyrauArmwrestlingSetup.exe`.
2. Если Windows SmartScreen покажет предупреждение «Неопознанное приложение» —
   нажмите **«Подробнее» → «Выполнить в любом случае»**.
   (Приложение не подписано цифровым сертификатом — это нормально для
   локальной сборки. Файл собран вами из исходного кода.)
3. В мастере установки нажмите **«Далее»** (или «Установить»).
4. По желанию отметьте галочку «Создать ярлык на рабочем столе».
5. Дождитесь завершения установки.

Приложение установится в папку `Program Files\Atyrau Armwrestling`
(или `%LOCALAPPDATA%\Programs\...`, если вы выбрали установку без прав
администратора). Ярлыки появятся на рабочем столе и в меню «Пуск».

---

## Шаг 3. Запустите приложение

Запустите **«Atyrau Armwrestling»** двойным кликом по ярлыку на рабочем
столе (или из меню «Пуск»).

При первом запуске:

1. Откроется главное окно «🦾 ArmWrestling Tournament Manager».
2. Через ~3 секунды приложение **проверит связь с сервером синхронизации**:
   - внизу окна появится зелёный тост «🟢 Сервер синхронизации доступен» —
     интернет и связь с сайтом в порядке;
   - если интернета нет или сервер недоступен — появится оранжевый/красный
     тост с пояснением (проверьте интернет или адрес сервера). Приложение
     всё равно работает: действия записываются локально, а синхронизация
     повторится автоматически.

Первое окно — список соревнований. Он пустой, потому что это новый
компьютер. Данные попадут сюда двумя путями (Шаги 4–6).

---

## Шаг 4. Перенесите существующие соревнования (Export/Import)

Если на старом компьютере у вас уже есть соревнования, перенесите их через
файл `.armwrestling` — это работает без интернета.

### На старом компьютере (экспорт)

1. Откройте приложение и выберите турнир в списке (двойной клик).
2. В верхней панели нажмите **«📦 Экспорт»**.
3. Выберите место и сохраните файл `Имя_турнира.armwrestling`.
4. Перенесите этот файл на новый компьютер (флешкой/облаком).
   Файл целостный: при повреждении при переносе приложение откажет в
   импорте с понятным сообщением (SHA-256 checksum).

### На новом компьютере (импорт)

1. В главном окне нажмите **«📥 Импорт»** (кнопка вверху).
2. Выберите файл `.armwrestling`.
3. Подтвердите импорт — соревнование появится в списке со всеми
   участниками, сетками и результатами.

> Совет: перед переносом нажмите **«🚨 Аварийный экспорт»** на старом ПК —
> он сделает снимок турнира мгновенно, без проверок, на случай срочного
> переноса посреди соревнования.

---

## Шаг 5. Подключитесь к сайту (синхронизация)

Приложение само настраивает соединение с сайтом:
`https://atyrau-armwrestling-production.up.railway.app` — адрес уже внутри
программы, вручную ничего вводить не нужно.

- Каждое действие (создание турнира, участника, матча, победителя) уходит
  на сервер автоматически, если есть интернет.
- Если сети нет — действие выполняется локально и попадает в офлайн-очередь;
  при появлении интернета отправка повторяется сама.
- Статус синхронизации виден в верхней панели: «🟢 Все данные сохранены»,
  «🟡 …несинхронизировано…», «🔴 Есть ошибка синхронизации».

> Примечание: после импорта соревнования на новый ПК дождитесь, пока
> «🟡 Несинхронизировано: N» сменится на «🟢 Все данные сохранены» — это
> значит, все перенесённые операции дошли до сервера.

---

## Шаг 6. Создайте новое соревнование (если не переносите старое)

1. На главном экране нажмите **«+ Новый турнир»**.
2. Заполните название, дату, место, формат сетки (Double Elimination / Single).
3. Откройте турнир и добавьте категории и участников на вкладках.
4. Приступите к работе с сеткой, как вы это делали раньше.

---

## Шаг 7. Публичное табло (по желанию)

Приложение умеет показывать результаты на табло сайта:

1. В окне открытого турнира нажмите **«📡 Транслировать на табло сайта»**
   и укажите номер стола.
2. На любом устройстве с браузером откройте
   `https://atyrau-armwrestling-production.up.railway.app/competitions/7/board` —
   табло обновляется автоматически.

Локальное табло по сети (без сайта): кнопка **«📺 Табло»** открывает
`http://localhost:5000` в браузере этого же ПК.

## Где хранятся данные

Локальные данные лежат в папке приложения вне Program Files (чтобы Windows
не блокировал запись):

```
C:\Users\<имя-пользователя>\AppData\Roaming\AtyrauArmwrestling\
├── armwrestling.db      — соревнования, участники, сетки, результаты
├── sync_state.db        — очередь синхронизации + карта id
├── photos/              — локальные фото участников
├── photo_cache/         — кэш фото с сайта
└── backups/             — автоматические резервные копии (.armwrestling)
```

Автобэкапы: приложение регулярно сохраняет копию турнира в `backups/`
(хранится ~10 последних). Если база повредится, при старте оно предложит
восстановиться из последней копии автоматически.

---

## Как обновить приложение

1. Соберите новый установщик: `build\build_installer.bat` на вашем
   сборочном ПК (см. Приложение В).
2. Запустите новый `AtyrauArmwrestlingSetup.exe` на рабочем ПК — он
   обновит файлы, **не трогая ваши данные** в AppData.

---

## Как полностью удалить приложение

1. **Параметры Windows → Приложения → Установленные приложения**
   → найдите **«Atyrau Armwrestling»** → **Удалить**.
2. Ярлыки удалятся автоматически.
3. Локальные данные останутся. Если нужно удалить и их — вручную удалите
   папку `C:\Users\<имя>\AppData\Roaming\AtyrauArmwrestling\`.

> Важно: данные на сервере (опубликованные соревнования) удаление
> приложения НЕ затрагивает.

---

## Если что-то не работает

| Симптом | Причина / решение |
|---|---|
| SmartScreen предупреждает | Приложение не подписано — «Подробнее → Выполнить в любом случае» |
| Приложение не запускается | Проверьте, что антивирус не заблокировал exe; перезапустите ПК; установите заново |
| Тост «Сервер синхронизации недоступен» | Нет интернета или сайт недоступен. Работа продолжится локально; синк повторится сам |
| «🔴 Есть ошибка синхронизации» | Проверьте интернет и токен. Записи не потеряны — отправка повторяется автоматически |
| Не открывается табло на порту 5000 | Порт занят другим приложением — табло на этом порту недоступно, приложение работает |
| Потеря данных (сбой БД) | При старте предложит восстановить из `backups/` — подтвердите |

## Приложение А. Чего НЕ нужно на новом ПК

| Компонент | Нужен ли |
|---|---|
| Python / pip | ❌ Нет (всё внутри exe) |
| PostgreSQL | ❌ Нет (сервер на Railway) |
| Локальный backend | ❌ Нет (приложение ходит напрямую на production API) |
| Установка библиотек | ❌ Нет |
| Права администратора | ❌ Нет (можно без них) |
| Internet | ✅ Да, для синхронизации (офлайн работает локально) |

---

## Приложение Б. Портативная версия (без установки)

1. Распакуйте `AtyrauArmwrestling_Portable.zip` в любую папку.
2. Запустите `AtyrauArmwrestling.exe`.
3. Данные, как и в установленной версии, хранятся в
   `%APPDATA%\AtyrauArmwrestling` (не в папке программы), поэтому версия
   работает из любого места.

---

## Приложение В. Как собрать установщик заново (для разработчика)

На сборочном ПК (с Python):

```
build_installer.bat
```

Один запуск делает всё: генерирует иконку, собирает
`AtyrauArmwrestling.exe` (PyInstaller), компилирует
`AtyrauArmwrestlingSetup.exe` (Inno Setup) и создаёт портативный ZIP.
Подробности — в `build\build_installer.bat` и `build\setup.iss`.
